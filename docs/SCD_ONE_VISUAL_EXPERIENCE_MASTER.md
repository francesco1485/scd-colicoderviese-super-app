# SCD ONE — VISUAL & EXPERIENCE MASTER

Status: BLOCKING FOR SCD ONE UI  
Date: 2026-10-03

## Identity

SCD ONE must be recognizable before the user reads the logo.

Character:
SPORT + TERRITORY + FUTURE + EDITORIAL IMPACT + LIVE STATE + SPATIAL DEPTH + CLEAR ACTION.

It is a social/sport/transaction product, not a generic website.

## Palette

Source of truth: `config/scd-visual-system.json`.

Primary composition:
- Mineral Navy #031A35
- Deep Navy #052E59
- Lake #0B98DD
- SCD Blue #0870CF
- Cyan #20B7E6
- Muted Gold #F0B900
- Yellow #FFD500
- Warm White #FFFFFF
- Paper #EEF5FB
- Ink #123657

Do not introduce a replacement brand palette.

## Mobile shell

Bottom navigation:
HOME / CALENDAR / TEAMS / SOCIAL / PROFILE.

Top area stays compact.

Partner/sponsor rail is visible or one gesture away and must never hide critical navigation.

## Home composition

Preferred order:
1. LIVE/PULSE strip
2. spatial hero with useful state, not brochure copy
3. next verified match
4. SCD Week Friday-to-Friday
5. teams rail
6. Matchday / live state
7. Club Now / Newsroom
8. Social / Community
9. media highlights
10. events / tournaments
11. partner/sponsor rail
12. community/family services
13. Join / Profile / transactions

## SCD Week

Visual center of gravity is Friday/weekend.

Do not render an empty corporate calendar as the hero of club life.

Use clear states:
PROGRAMMATO / CONFERMATO / LIVE / COMPLETATO / RINVIATO / DA_VERIFICARE.

## Matchday

Matchday must feel live and sport-first.

Possible verified modules:
- opponent;
- competition/category;
- venue;
- time;
- countdown;
- lineup/call-up only when authorized;
- score/live events only when source exists;
- media;
- route/maps;
- post-match result/content.

Never fake live events.

## Social

Avoid a clone of generic social networks.

Use SCD-specific interaction:
- club feed;
- team/event stories;
- safe reactions;
- verified media;
- community calls-to-action;
- moderation/reporting;
- age/consent-aware publication.

## Transaction surfaces

Every action should show:
- what happens;
- required inputs;
- status;
- confirmation;
- next step;
- failure/retry;
- privacy context.

No CTA that leads to nowhere.

## Motion

Purposeful only:
- micro feedback ~180ms;
- panel transitions ~260ms;
- live-state pulse only when truly live;
- skeleton loading;
- contextual reveal;
- reduced-motion equivalent.

## Synthetic spatial language

Hero/background UI should not depend on stock photography.

Use original synthetic scenes, CSS/SVG/WebGL/Canvas or approved original generated visuals.

Official logos, club assets, opponent crests and sponsor wordmarks remain real assets.

## Reject immediately

- 2000-era portals;
- Bootstrap admin shell;
- WordPress theme composition;
- giant blue header bars;
- anonymous card walls;
- excessive white empty dashboards;
- framed phone on desktop;
- fake smart/live indicators;
- meaningless gradients;
- casino/neon/gambling aesthetics;
- motion without purpose;
- hidden sponsor value;
- missing focus/reduced-motion states.

## Visual evidence

No SCD ONE UI is release-ready without:
- screenshot/visual comparison;
- mobile + desktop verification;
- no overflow/clipping;
- focus/keyboard;
- contrast;
- reduced motion;
- loading/empty/error/offline/stale;
- official asset integrity;
- source-state verification.
