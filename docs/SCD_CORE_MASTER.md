# SCD CORE MASTER

**Name:** SCD CORE  
**Long name:** SCD CORE — Association Operating System  
**Tagline:** Il sistema operativo della società.

## Mission
Build a complete internal management platform for SCD and a scalable model for sophisticated association/club operations.

## Core
Secretariat, registrations, people/families/athletes/staff, teams, events, calendar fusion, facilities, Smart Facility, fields/spaces/changing rooms, assets, warehouse, kit, laundry, keys/access, maintenance, transport, documents, requests, communications, approvals, deadlines and reporting.

## Product standard
Action-first, role-aware, auditable, fast, dense but readable, automation-ready and source-of-truth disciplined.

## Smart Facility rule
Connected status must be real. Otherwise use READY_FOR_ADAPTER / NOT_CONNECTED / UNVERIFIED / MANUAL_CHECK_REQUIRED.

## Command
`SCDCORE:RUN` invokes `WEBAPP:MASTER`.
