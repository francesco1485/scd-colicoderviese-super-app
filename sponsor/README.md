# SCD Sponsor & Partnership Development

Web App gratuita e separata dedicata al progetto Sponsor SCD ColicoDerviese 2026-2028.

## Principi
- Nessun servizio a pagamento richiesto per la UI.
- GitHub Pages come hosting gratuito.
- Dati iniziali derivati dal Master Zero del 30/09/2026.
- Ricerca globale e assistente locale senza API a consumo.
- Scritture esterne disabilitate finché non viene collegato il backend gratuito SCD (Google Apps Script / Sheets / Drive).
