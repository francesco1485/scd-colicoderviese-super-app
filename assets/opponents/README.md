# Opponent Crests

Cartella canonica per gli stemmi reali delle squadre avversarie.

Naming consigliato: `<club-slug>__<season>__verified.<ext>`.

Ogni asset richiede provenienza verificabile. Se lo stemma non e' verificato, usare il placeholder neutro dell'interfaccia e lo stato `LOGO_DA_VERIFICARE`, non uno stemma generato.
