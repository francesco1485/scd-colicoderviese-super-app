# Agenti SCD

Ventuno agenti di ruolo per la S.C.D. ColicoDerviese. Si chiamano in chat: "usa l'agente scd-tesoreria per la chiusura di settembre", "chiedi a scd-bandi i bandi in scadenza".

| Agente | Cosa fa |
| --- | --- |
| scd-grafica | Disegna e migliora pagine, schermate, grafiche, partendo dalle piattaforme migliori |
| scd-loghi-idee | Trova gli stemmi reali degli avversari e idee da altre società |
| scd-bandi | Cerca bandi e contributi (Italia, Lombardia, UE, fondazioni) con scadenze |
| scd-mail | Smista la posta del club e prepara bozze di risposta |
| scd-messaggi | Prepara risposte a WhatsApp, Instagram, Facebook |
| scd-social | Piano editoriale, didascalie, grafiche Canva, script reel |
| scd-tesoreria | Quote, conto, fornitori, compensi, chiusura del mese (398/91) |
| scd-segreteria | Persone, tesseramenti, certificati, consensi, scadenze FIGC |
| scd-sponsor | Pipeline sponsor, offerta LED, contratti, CRM |
| scd-tesserati | Qualità dell'anagrafica tesserati, svincoli e trasferimenti |
| scd-atleti | Rose, convocabilità, certificati, presa visione delle convocazioni |
| scd-azioni | Coordina gli altri agenti su un obiettivo e riporta lo stato |
| scd-stratega | Priorità della settimana, rischi, decisioni da prendere |
| scd-figc-lnd | Portale FIGC/LND/SGS come anagrafica madre: dilettanti, SGS, Piccoli Amici, esteri, staff, mister, dirigenti, utenti; confronto con Tally, posta e app |
| scd-automazioni | Scenari Make e moduli Tally: errori, doppioni, consumi, modifiche sicure |
| scd-sviluppo | Sviluppo della Super App: codice, test, migrazioni pronte da approvare |
| scd-tornei | Tornei ed eventi: idee, formati, fornitori, società da invitare, regole FIGC |
| scd-scouting | Bacheca interna giocatori per DS e dirigenza: atleti con consenso e osservatorio sui maggiorenni |
| scd-territorio | Esigenze e abitudini della popolazione locale, idee per coinvolgere |
| scd-sociale | Sport inclusivo, disabilità, solidarietà, progetti con servizi sociali |
| scd-relazioni | Relazioni fra iscritti, famiglie, volontari, ex atleti e partner |

Regole: nessun agente invia, pubblica, paga o cambia ruoli, permessi, tesseramenti, presenze, documenti sensibili o tutela dei minori; preparano bozze e proposte, decide la Direzione. Lavorano dentro una sessione o in un'attività programmata: nessuno gira da solo 24 ore su 24.
