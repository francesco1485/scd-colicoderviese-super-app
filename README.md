# data/front-page

One file, `front-page.json`: the «Prima pagina» of the day of the S.C.D. ColicoDerviese app (UD-187).
Written every morning only by the scheduled task «SCD Prima pagina · Super Giornalista»; read by the app server
(apps/superapp/src/lib/front-page.functions.ts). Shown only on its own Rome day, VERIFIED items only.
Switch-off: set `"off": true`. Never put personal data or DA CONFERMARE items here.
