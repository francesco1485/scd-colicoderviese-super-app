# SCD ColicoDerviese Super App

Frontend mobile-first + Node proxy per l'ecosistema digitale S.D.C. ColicoDerviese.

- Home pubblica dinamica
- SCD Radar
- Area tifosi/community
- Tesseramento/pre-iscrizione
- Sponsor & partner hub
- Tornei, campi, biglietti, card, fantacalcio non monetario
- Safeguarding separato
- PWA installabile
- Backend Apps Script R20 tramite proxy server-side

Nessun provider di pagamento e nessun servizio a consumo obbligatorio.
