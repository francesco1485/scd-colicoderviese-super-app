# data/calendar-public

Public calendar of S.C.D. ColicoDerviese (schema `scd-calendar-public-v3`), read by the Super App server
(`apps/superapp/src/lib/calendar-bridge.server.ts`) and accepted only after `validateMirror`
(`apps/superapp/src/lib/calendar-mirror.ts`).

- Generated from the club's Master Calendario by `tools/sync/calendar_public_payload.py` (branch `staging/superapp`).
- Updated by the scheduled task "SCD Calendario · copia pubblica oraria" only when the master changes.
- Teams, dates, times, venues and opponents only: no personal data. Never edit by hand; never store anything else here.
