# SCD PERMANENT COMMANDS — MASTER

Questo file è vincolante per ogni sviluppo S.D.C. ColicoDerviese.

## 1. SCD EVOLUTION ENGINE — HUMAN CENTRIC CONTINUOUS EVOLUTION
La Super App è un ecosistema vivo. Non aspettare che qualcuno segnali cosa manca.

Ciclo:
ASCOLTA → OSSERVA → ANALIZZA → INDIVIDUA GAP → PROPONI → PRIORITIZZA → SVILUPPA → TESTA → CONFRONTA VISIVAMENTE → VERIFICA → APPROVA → PUBBLICA → MISURA → MIGLIORA.

La matrice di ascolto privacy-first considera:
PAGE_VIEW, CTA_CLICK, FORM_START, FORM_COMPLETE, FORM_ABANDON, API_ERROR, CLIENT_ERROR, SLOW_LOAD, SEARCH_USE, PWA_INSTALL, SHARE, RETURN_VISIT, NOTIFICATION_INTERACTION, FEATURE_USE, FEEDBACK_SUBMIT.

Non raccogliere password, PIN, contenuti dei moduli, safeguarding, documenti, dati sanitari, messaggi privati o altri dati sensibili non necessari.

Ogni proposta in APP EVOLUTION QUEUE deve contenere:
PROBLEMA, EVIDENZA, UTENTI INTERESSATI, SOLUZIONE, VALORE UTENTE, VALORE SOCIETÀ, VALORE COMMERCIALE, RISCHIO, COSTO, PRIORITÀ, CONFIDENZA, TEST, CRITERIO DI SUCCESSO.

## 2. PIXEL PERFECT SCD
Le tavole approvate sono la Source of Truth visiva. Vietato trasformare la Super App in template SaaS, gestionale generico o sito minimalista.

Test obbligatori: 360x800, 390x844, 393x852, 430x932.

## 3. APP, NON SITO
La Super App deve essere installabile come PWA e aprirsi in modalità standalone. Il sito SCD è una fonte/contenitore pubblico, non la forma finale dell'app.

Elementi app-first:
- app shell;
- installazione;
- navigazione inferiore;
- profilo;
- notifiche;
- cache/update controllati;
- servizi personali;
- scorciatoie;
- funzioni offline dove possibile.

## 4. ACCOUNT UNICO
Registrazione uguale per tutti. Ogni persona entra come UTENTE BASE. Nessuna scelta ruolo in registrazione e nessun secondo account.

La Direzione può aggiungere sullo stesso account: FAMIGLIA, ATLETA, MISTER, STAFF, DIRIGENTE, SEGRETERIA, TESSERAMENTI, TORNEI, DIREZIONE, ALTRO.

## 5. AVATAR PERSONALE
Ogni Utente Base può:
- usare una propria foto;
- creare un avatar calciatore SCD;
- scegliere ruolo, numero, pelle, capelli, espressione e divisa;
- salvare localmente;
- esportare PNG trasparente.

Default privacy: elaborazione sul dispositivo, senza invio automatico a servizi esterni.

## 6. MEDIA TRANSPARENTE — REGOLA ASSOLUTA
Loghi, stemmi, mascotte, avatar, icone e cutout non devono avere quadrati/rettangoli colorati estranei.

Formato canonico: PNG RGBA trasparente.

Pipeline:
INPUT → CLASSIFICA FOTO/LOGO/GRAFICA → VERIFICA ALPHA → RIMOZIONE FONDO SE NECESSARIA → TRIM → PNG RGBA → CONTROLLO VISIVO → PUBBLICAZIONE.

Gli asset ufficiali non vanno ridisegnati. Si può solo rimuovere lo sfondo estraneo preservando forma, proporzioni e colori.

Fotografie hero/territorio/reportage possono usare WebP/JPEG/AVIF perché sono sfondi fotografici.

## 7. SICUREZZA EVOLUTIVA
Analisi e proposta possono essere automatiche. Produzione critica mai autonoma per: permessi, ruoli, pagamenti, dati personali, documenti, tesseramenti, presenze, safeguarding e database critici.

Regola: TEST → VERIFICA → APPROVAZIONE → PRODUZIONE.
